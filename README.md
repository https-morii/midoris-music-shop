⚡ Midori’s Music Shop - C2C Audio Shop ★🎸🎧⋆｡ °⋆

💿 Projeto de e-commerce C2C desenvolvido em PHP, MySQL e CSS estilizado em Frutiger Aero / Nu-Metal, feito por Mirella Fernandes e Rafaela Veloso ☠️

~🛠️ Como rodar o projeto localmente:
1. Copie os arquivos para a pasta `htdocs` do XAMPP.
2. Inicie o Apache e o MySQL no XAMPP Control Panel.
3. Acesse o phpMyAdmin (`http://localhost/phpmyadmin`), crie o banco `midoris_music_shop` e importe o arquivo `midoris_music_shop.sql`.
4. Acesse no navegador: `http://localhost/midoris_music_shop/index.php`.
